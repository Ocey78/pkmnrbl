# Default controls

The Wii Remote is held sideways, with its D-pad on the left. These keyboard and
mouse controls operate player one:

| Keyboard / mouse | Wii Remote |
| --- | --- |
| W / A / S / D | Move up / left / down / right |
| Left mouse button | 2 |
| Right mouse button | 1 |
| Escape | + |
| Tab | - |
| E | A |

Escape sends the remote's + button. Close the window to quit. The current
native WPSE controller bridge supports buttons only; pointer tracking and
motion controls are not yet supported.

GameCube controls retain Space for A, Enter for Start, arrows for the D-pad,
and WASD for the main stick.
